Q1: Why might we consider using Git?

Answer: We might consider using Git to remotely access a project or workspace across multiple devices. Additionally, in group settings, Git is useful in tracking changes done by each member

Q2: What field could data science be applied to? Give an Example.

Answer: Data science could be applied in finance. An example is fraud detection, as ML models can track spending habits.


Q3: What is the difference between Merging and Rebasing?

Answer: Merging keeps all previous history the same by creating a new merge commit, but rebasing rewrites history by creating a linear timeline.
